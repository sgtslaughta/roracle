# Style guide

- Use the active voice; past tense for methods and results, present tense for established facts.
- One claim per sentence; put the strongest supporting citation next to it.
- Define every symbol and acronym at first use (`Long Form (ACR)`; "let $x$ denote ...").
- Use SI units with a space between number and unit (10 kg, not 10kg); no mph, lbs, inches.
- Every figure and table has a caption, alt text and a label (`{#fig:name}`), referenced as `@fig:name`.
- Report effect sizes with uncertainty, not only p-values.
- Keep the abstract self-contained: problem, method, main result, implication.
- State limitations and data availability explicitly.
- No raw HTML or TeX, no external images (use `data:` images), no scripts: the PDF build drops them.
