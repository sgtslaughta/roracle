# User guide

For researchers: how to find, read, annotate, label, upload and ask about papers, write drafts and work with agents in rOracle. These pages describe what you see and do in the web app. Terms such as visibility, labels and handoffs are defined in the [glossary](../glossary.md).

## Pages

- [Welcome to rOracle](getting-started.md): signing in, the layout, theme and the command menu
- [Your first hour](first-hour.md): a short checklist to get going
- [Keyboard shortcuts](keyboard-shortcuts.md): every key in one place
- [Finding papers](library-search.md): searching, filters, sorting, votes
- [Reading a paper](reader.md): the reader, focus mode, references, cited-by, identifiers
- [Notes and annotations](notes-annotations.md): note kinds, anchoring to a passage, community notes
- [Sensitivity labels](labels.md): what a label means to you and how to change one
- [Collections and sharing](collections-sharing.md): your private collections, who can see a document
- [Uploading papers](uploads.md): adding papers, duplicates, near-duplicates, titles
- [Asking questions](chat.md): asking questions, reader-aware context, citations, excludes and pins, sharing
- [Writing drafts](writing-drafts.md): profiles, checks, citations, PDF build, AI disclosure, review, co-authors
- [Hand work to an agent](handoffs-inbox.md): handoffs, agent proposals, the bell
- [Agents and tokens](agents-and-tokens.md): what agents can do, creating and revoking access tokens
- [Set up MCP, step by step](agents-mcp-setup.md): connect Claude Code, Claude Desktop or another client
- [Troubleshooting agents](agents-troubleshooting.md): 401, 403 and 429 errors, missing papers
- [Sharing help topics](sharing-help.md): link a colleague to one topic

## Where things are

| You want to | Go to |
|---|---|
| Find a paper | Library, or press `/` ([search](library-search.md)) |
| Jump to a page or paper by name | `Ctrl+K` or `Cmd+K` ([shortcuts](keyboard-shortcuts.md)) |
| Add a paper | My uploads ([uploads](uploads.md)) |
| Mark a paper sensitive | Pencil next to the label in the reader ([labels](labels.md)) |
| Ask a question about the library | Ask in the sidebar ([chat](chat.md)) |
| Write and publish a paper | Drafts in the sidebar ([writing drafts](writing-drafts.md)) |
| Decide on notes your agents suggested | Agent proposals in the sidebar ([inbox](handoffs-inbox.md#agent-proposals)) |
| Give an agent a piece of work | Continue in agent ([handoffs](handoffs-inbox.md#creating-a-handoff)) |
| Let an agent use rOracle as you | Settings, Access tokens ([tokens](agents-and-tokens.md)) |

If something here does not match what you see, tell your rOracle admin: the app and these pages are versioned together.
