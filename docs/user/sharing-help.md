# Sharing help topics

Send a colleague straight to the help topic that answers their question.

## Copy a link

Open Help with `?`, pick a topic and choose **Copy link to this topic**. Anyone who opens the link lands on that topic.

```text title="Example link"
https://roracle.example.internal/library#help-agents-mcp-setup
```

!!! tip "Links do not share papers"
    A help link only opens a help topic. It does not give anyone access to a paper, a chat or a collection.
