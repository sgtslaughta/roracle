# P5 Web Shell, Library, Reader & Uploads Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The rOracle web app as approved in the prototype: themed shell, library search with facets, reader pane with PDF rendering and focus mode, and My uploads — running against the real API or a built-in mock API.

**Architecture:** Vite + React + TypeScript SPA in `frontend/` (ADR-0012). shadcn/ui components vendored under `src/components/ui`. Server state via TanStack Query; routes via TanStack Router. A typed API client (`src/api/`) mirrors backend contracts (P1 `/me`, `/documents`, `/me/uploads`; P3 `/search`, `/documents/{id}`, votes, tags, references). MSW provides a mock API with the prototype's sample library when `VITE_MOCK=1`, so the UI works before/without the backend.

**Tech Stack:** Node ≥ 22, pnpm (via `corepack pnpm`), Vite, React 19, TypeScript (strict), Tailwind CSS v4, shadcn/ui (Radix), lucide-react, @tanstack/react-query, @tanstack/react-router, oidc-client-ts, pdfjs-dist, katex, msw, vitest + @testing-library/react, @fontsource-variable/newsreader, @fontsource-variable/manrope, @fontsource/stix-two-text.

**Spec:** `docs/spec.md` §6 (reader, focus mode, links), §11 (UI, tokens), §3 (visibility); prototype `https://claude.ai/artifact/23jPeygSNRunuQBE6qGXHt` (reference implementation of layout/behaviour; source at `docs/prototype/roracle.html`).

## Global Constraints

- Product name in UI: `rOracle`. Logo: `/logo.png`; favicon `/favicon.ico`; touch icon `/apple-touch-icon.png` (already in `frontend/public/`).
- Theme tokens exactly as spec §11 table; dark mode never near-black; theme toggle cycles `system → light → dark`, persisted in `localStorage` key `roracle-theme` (wrapped in try/catch).
- Fonts: Newsreader (reading text, headings, answers), Manrope (UI), STIX Two Text (math); all bundled via @fontsource; **no runtime CDN requests** (CI check: built `dist/` contains no `https://` font/script URLs).
- Depth: chrome < bg < raised cards (`--elev`), recessed wells (`--well`), lists = sunken tray (`--tray`) holding raised cards; values from the prototype.
- Contours: `scripts/gen-contours.mjs` (marching squares, 30 levels, fixed seed) writes `public/contour-main.svg` and `public/contour-side.svg`; applied as CSS masks coloured by `--contour`.
- Reader focus mode: toolbar button cycles `split → three-quarter (75vw) → full`; `Esc` steps back one level; level persisted in `localStorage` key `roracle-reader-focus`.
- Links: `/d/:docId`, `/d/:docId/v/:version`, hash `#p=<page>&c=<chunkId>`; search state in query string (`q, tags, year, file_type, org_unit, collection, author, sort, page`).
- Keyboard: `⌘K`/`Ctrl+K` palette, `/` focus search, `j`/`k` move results, `Enter` open, `Esc` close reader/palette.
- Accessibility: visible focus rings, all icon buttons have `aria-label`, `prefers-reduced-motion` respected.
- Mock mode: `VITE_MOCK=1 corepack pnpm dev` serves the prototype's 7 sample documents through MSW handlers implementing the same response shapes as the API.

## Review Focus

1. Expired/absent token → redirect to sign-in, not a blank page; 401 from API triggers silent renew once — Task 3.
2. Facets show only values present in current results; clearing a filter restores counts — Task 4.
3. Docling bbox origin is bottom-left (PDF points); highlight must be converted to PDF.js top-left viewport coordinates at any zoom — Task 5.
4. Reader at full-screen focus: `Esc` returns to three-quarter, then split; closing reader resets nothing else — Task 5.
5. Upload of a 600 MB file → client-side rejection message naming the 500 MB limit before any request — Task 6.
