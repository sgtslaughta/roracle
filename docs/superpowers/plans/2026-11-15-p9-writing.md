# P9 Paper Writing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Researchers (and their agents over MCP) write papers as Markdown drafts inside rOracle, validate them against admin-managed writing profiles, verify every citation against the library, build a PDF safely, and submit the result (optionally via org-unit review) into the normal ingest path with an AI-assistance disclosure.

**Architecture:** A draft is a `documents` row (visibility `private`/`shared`, no `document_versions` until submit, so it never reaches the library, search or ES) plus a `drafts` row (status, profile, co-authors, disclosure, acks) and immutable `draft_versions` (Markdown text). New package `roracle/writing/` holds profiles, Markdown parsing, checks, citation verification, build and submit. Submission builds a PDF and calls `ingest/intake.add_version` on the same document, so the paper keeps its id. Profiles are YAML (7 shipped files, admin overrides versioned in `writing_profiles`). MCP prompt/resources and the skill zip are generated from one source directory.

**Tech Stack:** P10 stack + `pyyaml` (explicit) + `pypandoc-binary` (pinned pandoc binary via the PyPI mirror, hash-locked in `uv.lock`; we call the binary directly, not pypandoc's API). Gotenberg Chromium route for HTML → PDF.

**Spec:** `docs/spec.md` §7 (MCP tools `save_draft`, `validate_draft`, `check_citations`, prompt `write_paper`), §8; ADR-0011.

## Global Constraints

- Migration `migrations/versions/0010_p9.py`: `revision = "0010"`, `down_revision = "0009"`. `models.py` is at the 500-line limit: new models live in `roracle/models_writing.py` (imports `Base` from `models`; `models.py` imports it at the bottom so `Base.metadata` sees the tables).
- **Draft access (not `visible_documents`)**: read/save = admin, owner, or a co-author (`drafts.coauthors` user id or group the caller is in). Owner-only: share/co-authors, delete, submit. Anyone else → 404 `{"detail":"not found"}`. After publication the document may be `everyone`, but draft *content* stays co-author-only.
- While `drafts.status in ('draft','in_review')`: document visibility is `private` (no co-authors) or `shared` (DocumentShare rows = co-authors); `PATCH /documents/{id}` on such a document → 409 `{"detail":"use the /drafts endpoints"}`.
- Draft content ≤ `ROR_DRAFT_MAX_BYTES` (2 MiB, UTF-8) → 413. Content is untrusted everywhere (Markdown, front matter, citations, image URLs).
- Draft Markdown: optional YAML front matter (`title`, `authors`, `keywords`, `abstract`, `doc_type`, `format: markdown|latex`, `ai_assistance: {used: bool, tools: [str], description: str}`); sections are ATX headings; citations are pandoc citations with keys `@doc:<document_uuid>` or `@psg:<version_uuid>:<n>` (a chunk id), e.g. `[@doc:…; @psg:…:12]`; cross-refs `{#fig:x}`/`{#tbl:x}`/`{#sec:x}`/`{#eq:x}` labels and `@fig:x` references.
- Rule severities per profile: `blocking` | `warning` | `off`. Deterministic rules may block; LLM rules default to `warning` (admin may set `blocking`).
- Reports are stored on the draft version they were computed for: `draft_versions.validation` and `.citations` (jsonb). Submit uses the latest version's stored reports; missing/stale → 409.
- LLM calls use the OpenAI client from `search_routes.get_llm` and model `settings.writing_model or settings.chat_model_list[0]`; tests use fakes (Ollama off). Judge/LLM outage → validation warning `style check unavailable`; `check_citations` → 503 (no report stored).
- Every new MCP tool goes through `server._run` (own session, `audit("mcp.<tool>")`, ToolError). `save_draft` needs `write` scope.
- Admin routes use `require_admin` (P10) and add a second audit row with a body summary on mutation.
- Tests: `ROR_DATABASE_URL=postgresql+psycopg://roracle:roracle@localhost:55433/roracle_p9_test` on every run; integration inside `flock /tmp/roracle-integ.lock`; fakes only (no e2e). Pandoc tests `skipif` the binary is absent. Files < 500 lines; `uv run ruff check . && uv run ruff format --check .` clean.

## Review Focus

1. Draft content/versions/reports reachable only by owner, co-authors, admin; nothing about a draft leaks via library, search, `/me/uploads`, notifications or citation resolution — Task 2 (opus).
2. `check_citations` never resolves or quotes a document/passage the author cannot read (R19: PG post-filter; invisible and nonexistent look identical) — Task 4 (opus).
3. Build sandbox: no raw HTML/TeX passthrough, no external fetches (images, CSS, fonts), no user Lua filters, pandoc `--sandbox`, timeouts, input/output caps, CSP in the HTML — Task 5 (opus).
4. Submit blocked by unacked blocking findings / unresolved or unsupported citations / missing AI disclosure; disclosure stored and shown on the published document — Task 6.
5. Profile YAML validated (schema, size cap, `yaml.safe_load`), versioned, admin-only + audited — Task 1.

## Rulings (plan-level)

- R1: Draft = document row without versions + `drafts` side table (spec "private documents in draft state") — keeps sharing/ids and stays out of every library/search query for free — cost if wrong: a consumer listing raw `documents` without versions could show an empty row to owner/co-authors only.
- R2: Co-authors live in `drafts.coauthors` (`{"users": [...], "groups": [...]}`), mirrored into `document_shares` while drafting ("existing sharing"); draft content access uses `coauthors`, not document visibility — cost: two places to keep in sync (one function does it).
- R3: Co-authors may save versions; only the owner shares, deletes, submits.
- R4: Profile resolution: explicit `profile` name on the draft; else the newest active DB profile whose `org_units` contains an ancestor of the draft's org unit and whose `doc_types` contains front-matter `doc_type`; else shipped `journal-article`. DB profile with the same name as a shipped file overrides it. Validation reports `{name, version, source: "builtin"|"db"}`.
- R5: Checks beyond the lead's list (theorem/proof, statistics reporting, reproducibility/data availability, ethics, limitations) are expressed as profile `required_sections` (deterministic) and in the LLM style guidance (warn); library-overlap and build-as-check deferred (build failures surface at build/submit).
- R6: Unsupported/unclear citation verdicts and unresolved keys block; acknowledgements are per `(key, sha256(sentence))` and survive re-saves while the sentence is unchanged.
- R7: Math in PDFs uses pandoc `--mathml` (Chromium renders MathML Core, no JS/CDN); KaTeX remains the UI renderer — cost: minor typographic differences vs the reader.
- R8: Builds are synchronous (`POST /drafts/{id}/build` returns the PDF) under `ROR_BUILD_TIMEOUT_S` (120). LaTeX: `Builder` protocol + `DisabledLatexBuilder` default (`ROR_LATEX_BUILDER=disabled` → 501 `LaTeX builds are not enabled`); the `latex-builder` service contract is documented, not implemented.
- R9: HTML → PDF uses a separate Chromium-enabled Gotenberg (`ROR_DRAFT_GOTENBERG_URL`), never the ingest instance. Empty → build 503 `build service not configured`.
- R10: Org-unit review is decided by admins (`require_admin`), triggered by profile `review_required: true`; approval rebuilds from the frozen submitted draft version — cost: reference metadata may change between submit and approval.
- R11: AI disclosure is required front matter (`ai_assistance.used` bool, `description` required when used); stored in `drafts.ai_disclosure` at submit and returned as `ai_disclosure` by `GET /documents/{id}`.
- R12: Notes on drafts (spec "UI renders read-only with notes") need versions; deferred to the web team (render-only of Markdown via `GET /drafts/{id}`).

### Task 1: Storage, writing profiles, admin CRUD

**Files:** `migrations/versions/0010_p9.py`; `roracle/models_writing.py`; `roracle/writing/__init__.py`, `roracle/writing/profiles.py`, `roracle/writing/profiles/*.yaml` (7: `dissertation`, `journal-article`, `conference-paper`, `technical-report`, `grant-proposal`, `literature-review`, `preregistration`); `api/routes/admin_writing.py`; `pyproject.toml` (+`pyyaml`); Tests `tests/test_p9_schema.py`, `tests/test_writing_profiles.py`.
**Schema:**
- `drafts(document_id uuid PK FK documents ON DELETE CASCADE, profile text null, status text CHECK in ('draft','in_review','submitted') default 'draft', coauthors jsonb default {"users":[],"groups":[]}, ai_disclosure jsonb null, acks jsonb default [], target jsonb null, submitted_version int null, review_note text null, created_at, updated_at)`.
- `draft_versions(id uuid PK, document_id uuid FK drafts ON DELETE CASCADE, version int, content text, author_id uuid FK users, created_at, validation jsonb null, citations jsonb null, UNIQUE(document_id, version))`.
- `writing_profiles(id bigserial PK, name text, version int, yaml text, spec jsonb, active bool default true, created_by uuid FK users null, created_at, UNIQUE(name, version))`.
**Interfaces (`profiles.py`):** pydantic `Profile` (extra=forbid): `name` (slug `^[a-z0-9-]{1,60}$`), `title`, `doc_types: list[str]`, `org_units: list[str]` (normalized paths), `template: str` (Markdown skeleton), `required_sections: list[str]`, `required_metadata: list[str]`, `limits: {words_max, abstract_words_max, title_chars_max, figures_max, references_max}` (all optional ints ≥ 1), `citation_style: "numeric"|"author-year"`, `acronym_allowlist: list[str]`, `style_guidance: str`, `review_required: bool = False`, `rules: dict[RuleName, "blocking"|"warning"|"off"]` with defaults (deterministic → blocking except `notation`, `acronyms`, `si_units` → warning; `style` → warning). `RuleName` ∈ `structure, limits, metadata, notation, acronyms, crossrefs, alt_text, si_units, ai_disclosure, citations, style`. `parse(yaml_text) -> Profile` (≤ 64 KiB, `yaml.safe_load`, ValueError with a short message), `builtin() -> dict[str, Profile]` (cached), `resolve(session, name, org_unit, doc_type) -> tuple[Profile, int, str]` per R4, `list_effective(session) -> list[dict]`.
**Routes:** `GET /admin/writing-profiles` (effective list: name, title, version, source, active), `GET /admin/writing-profiles/{name}` (all versions + yaml), `POST /admin/writing-profiles` body `{"yaml": str}` → new version (version = max+1, builtin counts as 0), 422 on invalid YAML/schema, `DELETE /admin/writing-profiles/{name}` → all DB versions `active=false` (falls back to builtin, 404 if none). Mutations add audit row `admin.writing_profile` `{name, version}`.

### Task 3: `validate_draft` (deterministic checks + LLM style)

**Files:** `roracle/writing/markdown.py` (front matter, sections, words, citations, labels, figures — regex, no new deps), `roracle/writing/checks.py` (pure functions), `roracle/writing/validate.py`; route in `api/routes/drafts.py` (or `drafts_checks.py` if > 500 lines); MCP tool `validate_draft`; Tests `tests/test_writing_checks.py`, `tests/test_validate_api.py`.
**Interfaces:** `parse(md) -> Parsed(meta: dict, body: str, sections: list[Section(level, title, line)], citations: list[Cite(key, sentence, line)], figures: list[Figure(alt, src, label, line)], labels: set[str], refs: list[(label, line)])` (front matter: `yaml.safe_load`, non-dict → issue). Each check `check_<rule>(parsed, profile) -> list[Finding(rule, message, line | None)]`:
- `structure`: each `required_sections` title present (case-insensitive, numbering stripped); `metadata`: `required_metadata` keys non-empty; `limits`: words (body excluding code/math/references section), abstract words, title chars, figures, distinct citations.
- `notation`: inline-math symbols (single letters / `\alpha`-style commands with optional sub/superscript) — first use must be in or after a sentence with a definition cue (`let`, `where`, `denote`, `define`, `is the`, `be the`) mentioning it; report each undefined symbol once.
- `acronyms`: `\b[A-Z][A-Z0-9]{1,6}s?\b` first occurrence must be inside or right after `Long Form (ACR)`; profile allowlist + headings/code/math ignored.
- `crossrefs`: every `@fig:/@tbl:/@sec:/@eq:` ref has a label; duplicate labels.
- `alt_text`: image with empty alt.
- `si_units`: non-SI/ambiguous units (`mph|kph|kmh|secs?|hrs?|mins|cc|gms?|lbs?|°F|inch(es)?`) and number-unit without space (`10kg`, except `%` and `°`).
- `ai_disclosure`: `ai_assistance` present, `used` bool, `description` non-empty when used.
- `citations`: keys parse as `doc:`/`psg:` UUID forms and resolve per Task 4 `resolve_keys` (deterministic part only).
- `style` (LLM): one call with profile `style_guidance` + first 12k chars; expects JSON `{"warnings": [{"message", "quote"}]}` (≤ 20 kept); bad JSON/outage → one warning `style check unavailable`.
`validate(session, llm, settings, p, doc_id) -> dict` → `{"version", "profile": {name, version, source}, "ok": bool, "blocking": [...], "warnings": [...]}` (`ok` = no blocking findings), stored on the latest `draft_versions.validation`. Route `POST /drafts/{id}/validate`. MCP `validate_draft(draft_id)`.
- [ ] Tests: one positive + one negative case per check (fixture Markdown strings); severity `off` drops, `warning` moves to warnings; fake LLM JSON → warnings, garbage → `style check unavailable`; report stored on the latest version; stranger → 404.
- [ ] **Commit** `feat(writing): validate drafts against writing profiles`

### Task 4: `check_citations` + acknowledgements (opus review)

**Files:** `roracle/writing/cite_check.py`; routes in drafts router file(s); MCP tool `check_citations`; Tests `tests/test_cite_check.py`.
**Interfaces:** `resolve_keys(session, p, keys) -> dict[key, Resolved | None]` — `doc:` via `notes.access.readable_doc_ids(p)` (visible + searchable for non-owners); `psg:` chunk fetched from ES by `chunk_id` with `acl_filter(p)` then `chat.access.visible_versions` (R19); invisible and nonexistent both `None`. `check(session, es, llm, settings, p, doc_id) -> dict`: ≤ `ROR_WRITING_MAX_CITATIONS` (200) citation sentences else 422; for each `(key, sentence)`: unresolved → `status "unresolved"`; `psg` → that passage; `doc` → `retrieval.search_chunks(query=sentence, doc_ids=[doc], size=3)` + `visible_versions` post-filter, best passage (no passage → `unsupported`, reason "no matching passage"); judge prompt (sentence + passage ≤ 1500 chars) → JSON `{"verdict": "supported"|"unsupported"|"unclear", "reason"}`; non-JSON → `unclear`. Item: `{key, sentence (≤ 300 chars), sentence_hash, status: "resolved"|"unresolved", verdict, reason, chunk_id, doc_id, title, acknowledged}`. Report `{"version", "ok", "items"}`; `ok` = every item supported or acknowledged. Unresolved items never include title/doc_id. LLM/ES outage → 503, nothing stored.
**Routes:** `POST /drafts/{id}/check-citations` → report (stored on latest version); `POST /drafts/{id}/citations/ack` `{key, sentence_hash, reason (1..500)}` (owner or co-author) → stored in `drafts.acks` with user + time, re-marks the stored report; `DELETE` same path with `{key, sentence_hash}`.
- [ ] Tests (FakeES + fake LLM): invisible doc and random UUID → identical `unresolved` items (no title); `psg` of an invisible version → unresolved even if ES returns it; supported/unsupported/unclear mapping; ack flips `ok`; ack survives a re-save with unchanged sentence, not with a changed one; > max citations → 422; LLM error → 503 and no stored report.
- [ ] **Commit** `feat(writing): verify citations against the library`

### Task 5: Build sandbox (opus review)

**Files:** `roracle/writing/build.py` (Builder protocol, `PandocBuilder`, `DisabledLatexBuilder`, `get_builder(settings, fmt)`), `roracle/writing/ast_sanitize.py` (pandoc JSON AST walk); route `POST /drafts/{id}/build`; `config.py` (`draft_gotenberg_url`, `build_timeout_s=120`, `build_max_pdf_bytes=100 MiB`, `latex_builder="disabled"`); `pyproject.toml` (+`pypandoc-binary`, pinned in lock); docs `docs/enterprise/latex-builder.md` (service contract), `deployment-guide.md`, `security.md`, `airgap-mirror-manifest.md`; Tests `tests/test_build.py`.
**Interfaces:** `class Builder(Protocol): def build(self, markdown: str, refs: list[Ref], profile: Profile) -> bytes` (PDF). `pandoc_path() -> str | None` (`shutil.which("pandoc")` else pypandoc bundled `files/pandoc`). Pipeline: (1) `pandoc --sandbox -f markdown-raw_html-raw_tex-raw_attribute-tex_math_single_backslash -t json` (stdin, `timeout`, stdout cap 50 MiB, env `{}` + `PATH`, cwd = fresh temp dir, `preexec_fn` setrlimit `RLIMIT_AS` 2 GiB / `RLIMIT_CPU` 60 s); (2) Python sanitizer: drop `RawBlock`/`RawInline`; `Image` src kept only if `data:image/(png|jpeg|gif|webp);base64,` else replaced by its alt text; `Link` targets kept only `http(s):`, `mailto:`, `#…`; `Cite` → `[n]` (numeric) or `(Author Year)` per profile using `refs`, unresolved → `[?]`; append a `References` section from `refs`; (3) `pandoc --sandbox -f json -t html5 -s --mathml --metadata title=<escaped>`; (4) insert `<meta http-equiv="Content-Security-Policy" content="default-src 'none'; img-src data:; style-src 'unsafe-inline'; font-src data:">` as the first `<head>` child plus a small inline print stylesheet; (5) POST `index.html` to `{draft_gotenberg_url}/forms/chromium/convert/html` (httpx, `build_timeout_s`, streamed, abort past `build_max_pdf_bytes`, must start `%PDF-`). Errors: `BuildError(user_message)` → 422; timeout/Gotenberg down → 503; LaTeX disabled → 501. Route resolves refs with `cite_check.resolve_keys` (author's view) and returns `application/pdf`.
- [ ] Tests: sanitizer unit tests on hand-built AST JSON (raw HTML dropped, `http://` image → alt text, `javascript:` link dropped, data-URI image kept, cite numbering); pandoc-backed tests (`skipif` no pandoc): `<img src=http://x>` and `<script>` absent from HTML, CSP meta first in `<head>`, math → `<math`; Gotenberg via `httpx.MockTransport` (oversize → 422-class error, non-PDF → error, timeout → 503); `format: latex` → 501; stranger → 404.

### Task 6: Submit, review, disclosure, `write_paper` prompt, resources, skill zip
