# Auto-tags plan (2026-11-17)

Goal: the LLM suggests up to 5 short topical tags from a version's AI summary; users see them as "auto",
can remove them, adopt them (adding flips `source` to `user`), and add tags straight from a library card.

## Tasks
1. **Schema** — migration `0021_tag_source`: `tags.source varchar(8) not null server_default 'user'`; `Tag.source`.
2. **Hints at parse** — `parse_tei` captures `<keywords>/<term>` into `meta.keywords` (≤20);
   `extract_arxiv_stamp` also returns the `[cs.XX]` category; `merge_page_ids` puts it in `meta.arxiv_category`
   (never in `meta.ids`).
3. **`roracle/autotag.py`** — `suggest(llm, model, title, summary, keywords, category, vocab)`: system prompt holds
   rules only; title/summary/hints go in the user turn inside `<paper>` via `chat.answer._quote`. Hint lines are
   omitted when absent. Output: JSON array → `normalize_tag`, drop empties/>3 words, dedupe, cap 5.
   `vocabulary(session)`: top 50 tag strings over live, `visibility='everyone'`, LLM-allowed documents.
   `apply(session, doc_id, tags)`: delete the doc's `llm` tags, insert new ones (`on conflict do nothing`, so a
   user tag is never touched), respect MAX_TAGS, enqueue `acl_sync` (ES tags converge like any tag change).
   `tag_version(...)`: gate (a) re-read of the label; no summary → nothing; any failure logged, never raised.
4. **Ingest** — after the summary, in the `parsed` stage: `tag_version` in a short fenced session; the version's
   `meta.auto_tagged=true` is set with the `summarized` stage update.
5. **Backfill** — job `auto_tags {version_id}` + `roracle auto-tags [--limit N]` (latest searchable versions with
   a summary, LLM-allowed label, not `meta.auto_tagged`, no queued job). Never removes user tags.
6. **API** — `add_tag` upserts `source='user'` (adopting an auto tag); search hits and document detail gain
   `auto_tags: string[]` (subset of `tags`).
7. **Frontend** — `TagChip` `auto` style + title "Suggested by AI from the summary"; `ResultCard` inline
   "+ tag" input reusing `useAddTag`; shared `normTag` helper.

## Tests (TDD)
Unit: prompt shape (quoted data, no hints when absent), parsing/normalisation/cap, stamp category, TEI keywords.
Integration: gate (a) no LLM call; summary-only doc gets tags; no summary → no call; LLM failure doesn't fail
ingest; adopt flips source; vocab excludes non-public docs; backfill enqueue + handler keeps user tags; ES tags.
